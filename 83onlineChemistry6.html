专题6 化学变化及其表示

课题1 化学反应中各物质间的定量关系

化学反应中物质的质量发生变化吗
  • 一、实验探究：化学反应前后物质的质量变化
    • 实验1：硫酸铜溶液与氢氧化钠溶液反应
      • 反应前总质量：85.9g
      • 实验现象：产生蓝色沉淀
      • 反应后总质量：85.9g
      • 反应方程式：CuSO_4 + 2NaOH \xlongequal{\quad} Cu(OH)_2\downarrow + Na_2SO_4
      • 实验结论：反应前后质量相等
    • 实验2：稀盐酸与大理石反应
      • 反应前总质量：78.4g
      • 反应后总质量：78.4g（没有密闭，但结果一样，高老师失败了）
      • 反应方程式：CaCO_3 + 2HCl \xlongequal{\quad} CaCl_2 + H_2O + CO_2\uparrow
      • 注意事项：实验需要在密闭容器中进行，因为反应会产生CO₂气体，不密封，气体会扩散，无法被测量
      • 实验结论：反应前后质量相等
    • 实验3：金属铜加热
      • 实验现象：铜丝由红色变为黑色
      • 反应方程式：2Cu + O_2 \xlongequal{\triangle} 2CuO
      • 实验结论：反应前后质量不变（提到，没有做）
  • 二、质量守恒定律
    • 无数实验证明，参加化学反应的各物质的质量总和，等于反应后生成的各物质的质量总和，这个规律叫做质量守恒定律。（P153）
    • 自18世纪以来，许多化学家用天平精确研究了化学反应过程中的质量关系后，才一致认为质量守恒是精确的科学定律。（P153）
如何从微观视角认识质量守恒定律
  • 1. 在化学变化中，参加反应的反应物质量之和，等于反应生成的生成物质量之和
  • 2. 在化学变化中，原子的种类与个数不变
  • 3. 在化学变化中，元素的种类与质量不变
  • 所有的化学反应都是各反应物中的原子经过重新组合形成新物质的过程。（P154）

课题2 化学反应的表示及基本类型

如何表示化学反应
  • 我们可以用包含化学式的式子来表示化学反应，这种式子叫做化学方程式。（P157）
  • 化学反应都遵守质量守恒定律，化学方程式不仅表明反应物、生成物和反应条件，还表明参加化学反应的原子和分子的数量关系，化学反应前后原子种类不变，原子数目也保持不变。（P157）
如何书写化学方程式
  • 一、书写原则
    • 以客观事实为基础：不能凭空臆造不存在的物质和反应
    • 遵守质量守恒定律：反应前后原子的种类、数目、质量不变
  • 二、书写步骤
    • 1. 写：写出反应物和生成物的化学式（短线连接）
    • 2. 配：配平化学方程式（使两边各原子数目相等）
    • 3. 注：注明反应条件（如点燃、加热△、通电、催化剂等）
    • 4. 等：将短线改为等号
    • 5. 标：标注生成物状态（↑气体、↓沉淀，反应物有气体则生成物不标↑）
化学方程式中蕴含着哪些信息
  • 一、化学方程式的含义
    1. C + O_2 \xlongequal{\text{点燃}} CO_2
      • 物质：碳与氧气在点燃条件下反应，生成二氧化碳
      • 微观：
        • 每1个碳原子和1个氧分子在点燃条件下反应，生成1个二氧化碳分子
        • 每12克碳与32克氧气反应，生成44克二氧化碳
    2. 2H_2O \xlongequal{\text{通电}} 2H_2\uparrow + O_2\uparrow
      • 物质：水在通电条件下生成氢气和氧气
      • 微观：
        • 在通电条件下，每2个水分子反应生成2个氢分子和1个氧分子
        • 在通电条件下，每36克水分解，生成4克氢气和32克氧气
  • 二、化学方程式的质量计算问题
    • 1. 计算方法（严按格式）
      1. 设：设未知数
      2. 写：写出配平的化学方程式
      3. 比：写出相关物质的相对质量比
      4. 对：对应位置写上已知和未知量
      5. 列：列出比例关系
      6. 算：通过比例式求解
      7. 答：写出答句（带单位）
    • 2. 举例
      • 题目：若要得到2g氢气，需要分解多少水？
      • 解：
      • 设：需要分解xg水
      • 2H_2O \xlongequal{\text{通电}} 2H_2\uparrow + O_2\uparrow
        2×（1×2+16×1）=36 ： 2×（1×2）=4
        36 ： 4
        x ： 2
      • \frac{36}{x} = \frac{4}{2}
      • x = 18g
      • 答：需要分解18g水。
有哪些化学反应的基本类型
  • 一、化合反应
    • 定义：由两种或两种以上物质生成另一种物质的反应
    • 特点：多变一
    • 表达式：A+B+...\rightarrow C
    • 举例：
      • 2H_2 + O_2 \xlongequal{\text{点燃}} 2H_2O（氢气燃烧）
      • C + O_2 \xlongequal{\text{点燃}} CO_2（碳完全燃烧）
      • CaO + H_2O \xlongequal{} Ca(OH)_2（生石灰与水反应）
  • 二、分解反应
    • 定义：由一种物质生成两种或两种以上其他物质的反应
    • 特点：一变多
    • 表达式：A\rightarrow B+C+...
    • 举例：
      • 2H_2O \xlongequal{\text{通电}} 2H_2\uparrow + O_2\uparrow（水电解）
      • 2KMnO_4 \xlongequal{\Delta} K_2MnO_4 + MnO_2 + O_2\uparrow（高锰酸钾分解）
      • CaCO_3 \xlongequal{\text{高温}} CaO + CO_2\uparrow（碳酸钙分解）
  • 三、置换反应
    • 定义：由一种单质与一种化合物反应，生成另一种单质和另一种化合物的反应
    • 特点：单换单
    • 表达式：A+BC\rightarrow AC+B
    • 举例：
      • Fe + CuSO_4 \xlongequal{} FeSO_4 + Cu（铁与硫酸铜反应）
      • Zn + H_2SO_4 \xlongequal{} ZnSO_4 + H_2\uparrow（锌与稀硫酸反应）
      • H_2 + CuO \xlongequal{\Delta} Cu + H_2O（氢气还原氧化铜）
  • 四、复分解反应
    • 定义：由两种化合物互相交换成分，生成另外两种化合物的反应
    • 特点：双交换
    • 表达式：AB+CD\rightarrow AD+BC
    • 举例：
      • NaOH + HCl \xlongequal{} NaCl + H_2O（酸碱中和）
      • CaCO_3 + 2HCl \xlongequal{} CaCl_2 + H_2O + CO_2\uparrow（碳酸钙与盐酸反应）
      • AgNO_3 + NaCl \xlongequal{} AgCl\downarrow + NaNO_3（硝酸银与氯化钠反应）
  • 五、其他分类视角
    • 以某些反应中物质是否“失去氧或得到氧”，可判断其是否属于还原反应和氧化反应。例如，氢气与氧化铜反应，生成铜和水。在这个反应里，氧化铜失去氧而变成单质铜，这种含氧化合物里的氧被夺去的反应，属于还原反应；氢气得到氧而变成水的反应，属于氧化反应。（P162）
    • 若从化学反应过程中能量变化的视角来看，则可分为放热反应和吸热反应。除了化学反应的基本类型，我们可从不同的分类视角来认识化学反应，分类的标准不同，分类的结果就不同。（P162）

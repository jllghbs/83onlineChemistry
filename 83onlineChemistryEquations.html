    • 现象：发出耀眼白光，生成白色固体，放热

专题三 空气、氧气、二氧化碳

课题1 空气的成分
  • 4\text{P} + 5\text{O}_2 \xlongequal{\text{点燃}} 2\text{P}_2\text{O}_5 氧化反应 化合反应 点燃
    • 现象：产生大量白烟，放热
    • 应用：测定空气中氧气的含量
    • 测定结果偏小（进入瓶内水的体积小于⅕：
      • ① 红磷用量不足，无法将装置内氧气完全消耗
      • ② 装置气密性不好，反应后外界空气进入集气瓶
      • ③ 未冷却至室温就打开弹簧夹，瓶内气体受热膨胀，压强偏大
      • ④ 导管内事先未注满水，部分水残留在导管中
    • 测定结果偏大（进入瓶内水的体积大于⅕：
      • ① 点燃红磷后，伸入集气瓶速度过慢，瓶内部分空气受热逸出
      • ② 实验前未夹紧弹簧夹，红磷燃烧时瓶内气体受热从导管逸出
课题2 氧气和二氧化碳的性质
  • \text{C} + \text{O}_2 \xlongequal{\text{点燃}} \text{CO}_2 氧化反应 化合反应 点燃
    • 现象：空气中：红热；氧气中：发白光，放热
    • 注意：此反应为氧气充足时的完全燃烧
  • 3\text{Fe} + 2\text{O}_2 \xlongequal{\text{点燃}} \text{Fe}_3\text{O}_4 氧化反应 化合反应 点燃
    • 现象：火星四射，剧烈燃烧，生成黑色固体，放热
    • 注意事项：
      • 实验中需用火柴引燃铁丝
      • 集气瓶底部需预先加水或铺一层细沙，防止反应生成的高温熔融物溅落导致集气瓶炸裂
  • \text{CO}_2 + \text{H}_2\text{O} \xlongequal{\quad} \text{H}_2\text{CO}_3 化合反应
    • 现象：紫色石蕊试液变红
  • \text{H}_2\text{CO}_3 \xlongequal{\triangle} \text{H}_2\text{O} + \text{CO}_2\uparrow 分解反应 加热
    • 现象：红色石蕊试液变紫
  • \text{CO}_2 + \text{Ca(OH)}_2 \xlongequal{\quad} \text{CaCO}_3\downarrow + \text{H}_2\text{O} 复分解反应
    • 现象：澄清石灰水变浑浊
    • 应用：检验二氧化碳的方法
课题3 氧气和二氧化碳的制备
  • 2\text{H}_2\text{O}_2 \xlongequal{\text{MnO}_2} 2\text{H}_2\text{O} + \text{O}_2\uparrow 分解反应 催化剂
    • 发生装置：固液常温型
    • 催化剂：不参与反应，反应前后质量和化学性质不变
  • 2\text{KMnO}_4 \xlongequal{\triangle} \text{K}_2\text{MnO}_4 + \text{MnO}_2 + \text{O}_2\uparrow 分解反应 加热
    • 发生装置：固体加热型
    • 收集方法：排水法或向上排空气法
    • 验满方法：
      • 排水法：集气瓶口有大量气泡冒出时，说明已集满
      • 向上排空气法：将带火星的木条放在集气瓶口，木条复燃则已集满
    • 注意事项：
      • ① 试管口放一小团棉花，防止高锰酸钾粉末进入导管
      • ② 试管口略向下倾斜，防止冷凝水倒流使试管炸裂
      • ③ 实验结束时先移出导管，再熄灭酒精灯，防止水槽中水倒流使试管炸裂
  • 2\text{KClO}_3 \xlongequal[\triangle]{\text{MnO}_2} 2\text{KCl} + 3\text{O}_2\uparrow 分解反应 加热 催化剂
  • \text{CaCO}_3 + 2\text{HCl} \xlongequal{\quad} \text{CaCl}_2 + \text{H}_2\text{O} + \text{CO}_2\uparrow 复分解反应
    • 发生装置：锥形瓶、长颈漏斗或分液漏斗、双孔橡皮塞、导气管
    • 收集方法：向上排空气法（二氧化碳密度比空气大，能溶于水且与水反应）
    • 验满方法：将燃烧的木条放在集气瓶口，木条熄灭则已集满
    • 注意事项：
      • 长颈漏斗下端需伸入液面以下形成液封，防止气体从漏斗口逸出
      • 不可用稀硫酸，因为生成的硫酸钙微溶于水，会覆盖在碳酸钙表面使反应停止
      • 不可用粉末状大理石，反应速率过快，不易收集

专题四 水的性质与组成

课题1 水的性质
  • \text{CaO} + \text{H}_2\text{O} \xlongequal{\quad} \text{Ca(OH)}_2 化合反应
    • 现象：放出大量热
    • 冷却后加入酚酞试液，溶液变红（碱性）
课题3 水的组成
  • 2\text{H}_2 + \text{O}_2 \xlongequal{\text{点燃}} 2\text{H}_2\text{O} 氧化反应 化合反应 点燃
    • 现象：发出淡蓝色火焰，烧杯内壁有小液滴
  • 2\text{H}_2\text{O} \xlongequal{\text{通电}} 2\text{H}_2\uparrow + \text{O}_2\uparrow 分解反应 通电
    • 现象：电极上有气泡产生，正负极产生气体，体积比1:2
    • 气体检验：
      • 正极（氧气）：用带火星的木条检验，木条复燃
      • 负极（氢气）：点燃，产生淡蓝色火焰
    • 结论：证明水由氢元素和氧元素组成

专题五 物质的微观构成

课题3 结构多样的碳单质
  • \text{C} + \text{O}_2 \xlongequal{\text{点燃}} \text{CO}_2 氧化反应 化合反应 点燃
    • 碳的完全燃烧
    • 现象：空气中：红热；氧气中：发白光，放热
  • 2\text{C} + \text{O}_2 \xlongequal{\text{点燃}} 2\text{CO} 氧化反应 化合反应 点燃
    • 碳的不完全燃烧
  • \text{C} + 2\text{CuO} \xlongequal{\text{高温}} 2\text{Cu} + \text{CO}_2\uparrow 氧化反应 还原反应 置换反应 高温 需要使用酒精喷灯
    • 现象：黑色固体变红色，澄清石灰水变浑浊
    • 注意事项：
      • ① 先移导管再熄灭酒精灯，防止石灰水倒流使试管炸裂
      • ② 若先熄灭酒精灯再移导管，会使生成的铜重新被氧化
      • ③ 应该使用止水夹再熄灭酒精灯并移出导管
  • \text{C} + \text{CO}_2 \xlongequal{\text{高温}} 2\text{CO} 氧化反应 高温
    • 现象：黑色固体减少

专题六 化学变化及其表示

课题1 化学反应中各物质间的定量关系
  • \text{CuSO}_4 + 2\text{NaOH} \xlongequal{\quad} \text{Cu(OH)}_2\downarrow + \text{Na}_2\text{SO}_4 复分解反应 常温
    • 现象：生成蓝色沉淀
  • \text{CaCO}_3 + 2\text{HCl} \xlongequal{\quad} \text{CaCl}_2 + \text{H}_2\text{O} + \text{CO}_2\uparrow 复分解反应
    • 现象：有气泡产生，固体逐渐溶解
    • 注意：必须在密闭容器中进行，否则二氧化碳会扩散到空气中，导致气体无法被测量

# 83onlineChemistry
# 初中电子化学笔记

> Online Chemistry Notes for Shanghai Science and Technology Press
> 沪科版（五·四学制） 化学在线笔记

This repository is a full online HTML note system compiled based on the chemistry textbook of Shanghai Science Press (5-4 School System). It covers all ten textbook topics and provides auxiliary tools including quick lookup of chemical equations, summary of key knowledge points, and AI Q&A.
本仓库是一套基于沪科版（五·四学制）化学教材编写的**在线 HTML 笔记系统**，涵盖教材全部十个专题，并提供方程式速查、知识要点汇总、AI 问答等辅助工具。

## Core Features
## 功能特性

- **Pure Static HTML**: No server required; double-click to open directly in browsers
  **纯静态 HTML**：无需服务器，双击即可在浏览器中使用
- **KaTeX Typesetting**: KaTeX renders chemical formulas and mathematical equations on Topic 4–6 and tool pages
  **KaTeX 排版**：专题四至六及工具页使用 KaTeX 渲染化学式与数学公式
- **Settings Panel**: Adjust font size, line spacing, character spacing; support theme switching and background image toggle
  **设置面板**：可调整字号、行间距、字间距，支持主题切换与背景图开关
- **Search Function**: Built-in search boxes for fast knowledge positioning
  **搜索功能**：内置搜索框，快速定位知识点
- **Tag Filter**: Chemical equation page supports filtering via reaction type tags
  **标签筛选**：方程式大全页支持按反应类型标签筛选
- **AI Q&A**: Built-in AI dialogue interface for instant chemistry inquiry
  **AI 问答**：内置 AI 对话界面，支持化学问题即时提问

番外篇 化学99条大全

本学期核心知识点（千万不要考试的时候往考卷上默99条哦！！！）

  • 不能在化学课上挑衅、激怒化学老师
  • 上课禁止写作业（刘育君除外）
  • 上课不能阅读《嫌疑人x的献身》并向高老师泄露情节
  • 考试结束后需立刻停笔，不能拿着卷子冲出教室
  • 禁止使用AI化学老师工具问奇奇怪怪的问题或进行恶搞
  • 水是由大量水分子构成的
  • 水的三态为固态冰、液态水、气态水蒸气
  • 水的三态变化属于物理变化，水分子本身不发生改变
  • 水的三态变化只改变分子间的间隔和排列方式
  • 温度越高，分子的运动速率越快
  • 一般情况下，温度升高，分子之间的间隔会变大
  • 水的三态变化过程中会伴随能量的吸收或释放
  • 由分子构成的物质多是非金属化合物和气态非金属单质，例如H₂O、O₂
  • 由原子直接构成的物质多是金属、稀有气体和部分固态非金属，例如Fe、He
  • 由分子构成的物质，分子是保持其化学性质的最小粒子
  • 分子的基本性质：质量和体积都很小；分子之间有间隔；分子在不断运动
  • 常温常压下，水是无色、无味的透明液体
  • 标准大气压下，水的凝固点为0℃，沸点为100℃
  • 水在4℃时密度最大，数值为1g/cm³
  • 冰的密度比水小，所以冰能浮在水面上
  • 水具有反常膨胀的特点：0~4℃时温度升高体积减小，高于4℃时温度升高体积增大，导致相同质量的冰体积比水大，密度比水小
  • 水的比热容较大，吸热和放热能力强，常被用作冷却剂或调节温度的介质
  • 水是常见的优良溶剂，能溶解食盐、蔗糖等多种物质形成溶液
  • 水具有毛细现象，可以沿着细小孔隙向上移动
  • 水具有表面张力，能支撑较轻的物体停留在水面
  • 水和二氧化碳的反应：
    • 水与二氧化碳反应生成碳酸
    • 反应表达式：H_2O + CO_2 \xlongequal{\quad} H_2CO_3
  • 水与氧化钙的反应：
    • 氧化钙与水反应生成氢氧化钙，同时放出大量热
    • 反应表达式：CaO + H_2O \xlongequal{\quad} Ca(OH)_2
  • 氢氧化钙：俗称熟石灰，微溶于水，溶液呈碱性，能使无色酚酞试液变红；生石灰的主要成分是氧化钙
  • 自然界中的水含有杂质，矿泉水、河水、井水等天然水都属于混合物
  • 氯气常用来对自来水进行杀菌消毒
  • 硬水是含有较多可溶性钙、镁化合物的水
  • 软水是不含或含较少可溶性钙、镁化合物的水
  • 地球表面约71%被水覆盖，地球上的水中，咸水约占97%，淡水约占3%，但可直接利用的淡水资源很少，不足总水量的1%
  • 氢气燃烧的操作是点燃纯净氢气，火焰上方罩干冷烧杯；现象是产生淡蓝色火焰，烧杯内壁出现水雾
  • 氢气燃烧化学表达式：2H_2 + O_2 \xlongequal{\text{点燃}} 2H_2O；结论：证明水由氢、氧元素组成
  • 电解水装置与现象：装置为水电解器、直流电源、水；水位控制通过上下调整漏斗（连通器原理）使玻璃管充满水；通电后两极均产生气泡，负极产生气泡更快，正、负极气体体积比为1:2
  • 电解水正负极气体：正极产生氧气（能使燃着木条燃烧更旺），负极产生氢气（点燃后产生淡蓝色火焰）
  • 电解水化学表达式为2H_2O \xlongequal{\text{通电}} 2H_2\uparrow + O_2\uparrow；结论：证明水由氢、氧元素组成；氢、氧气体积比2:1说明水分子中氢、氧原子个数比2:1
  • 水分解微观过程：水分子分裂为氢原子和氧原子，氢原子重新结合形成氢分子，氧原子重新结合形成氧分子；说明化学变化中分子可分，原子不可分
  • 化合反应：两种或多种物质生成一种物质，特点是多变一，表达式为A+B+\dots\rightarrow C
  • 化合反应举例：2H_2 + O_2 \xlongequal{\text{点燃}} 2H_2O
  • 分解反应：一种物质生成两种或多种物质，特点是一变多，表达式为A\rightarrow B+C+\dots
  • 分解反应举例：2H_2O \xlongequal{\text{通电}} 2H_2\uparrow + O_2\uparrow
  • 置换反应："单换单"，由一种单质与一种化合物反应，生成另一种单质和另一种化合物，特点是单换单，表达式为A+BC\rightarrow AC+B
  • 置换反应举例：Fe + CuSO_4 \xlongequal{} FeSO_4 + Cu
  • 复分解反应："双交换"，由两种化合物互相交换成分，生成另外两种化合物，特点是双交换，表达式为AB+CD\xlongequal{} AD+BC
  • 复分解反应举例：NaOH + HCl \xlongequal{} NaCl + H_2O
  • 物质的宏观组成：指物质由元素组成，仅说种类、不说个数
  • 物质的微观构成：指物质由离子、分子、原子构成，既说种类、也说个数
  • 离子的定义与对应物质：带电荷的微观粒子；对应物质为金属化合物（如NaCl）
  • 分子的定义与对应物质：由原子构成的微观粒子；对应物质为非金属单质（如O₂、N₂）、非金属化合物（如CO₂、H₂O）
  • 原子的定义与对应物质：化学变化中的最小微观粒子；对应物质为金属单质（如Fe、Cu）、非金属固体单质（如C、P）、稀有气体（如He、Ne）
  • 元素的定义：质子数相同的同一类原子的总称（宏观层面，是原子的集合）
  • 微观粒子的基本性质：①体积小、质量小；②不断运动；③粒子间有间隔；④同种粒子性质相同，不同粒子性质不同
  • H₂O的宏微观含义：
    • 宏观：①代表物质（水）；②由氢元素和氧元素组成
    • 微观：①代表1个水分子；②1个水分子由2个氢原子和1个氧原子构成
  • 3SO₂的宏微观含义：
    • 化学式前加数字后，只能表示微观意义，无宏观意义
    • 微观：①代表3个二氧化硫分子；②1个二氧化硫分子由1个硫原子和2个氧原子构成
  • 原子结构：由原子核（含质子带正电、中子不带电，氢原子无中子）和核外电子（带负电）构成；核外电子排布规律：电子层最多容2n²个电子，最外层不超8个（第一层不超2个），先排内层再排外层
  • 元素周期表的基本排布：按原子序数排，周期数=电子层数，主族数=最外层电子数（0族除外）
  • 化合价：定义为形成化合物时一个原子和其他原子相结合的数目；规则是化合物中正负化合价代数和为0，单质中元素化合价为0
  • 常见元素的化合价：
    • +1价：K、Na、Ag、H
    • +2价：Ca、Mg、Ba、Zn、Cu、Fe（亚铁）
    • +3价：Al、Fe（铁）
    • -1价：F、Cl
    • -2价：O、S
  • 常见原子团的化合价：
    • +1价：NH₄⁺（铵根）
    • -1价：OH⁻（氢氧根）、NO₃⁻（硝酸根）
    • -2价：CO₃²⁻（碳酸根）、SO₄²⁻（硫酸根）
  • 金属化合物的读写规则：
    • 读法：从右向左读“某化某”
    • 写法：正价在前，负价在后
  • 非金属化合物的读写规则：
    • 读法：读“几某化几某”
    • 写法：正价在前，负价在后
  • 原子结构模型（实心球模型）：道尔顿1803年提出，认为原子是不可再分的实心球体
  • 原子结构模型（葡萄干面包模型）：汤姆孙1903年提出，认为原子像蛋糕、电子像葡萄干嵌在其中（无核结构）
  • 原子结构模型（核式结构模型）：卢瑟福1911年提出，认为原子中心有带电原子核，核外电子绕核运动
  • 碳单质的多样性原因：同种碳元素组成不同单质，本质是碳原子的排列方式不同
  • 石墨的性质与用途：质柔、黑色、有导电性和滑腻感，层状结构，可作铅笔芯、电极、润滑剂
  • 金刚石的性质与用途：天然最硬物质、折射率高，正四面体结构，可作钻头、装饰品、切割工具
  • 金刚石与石墨的转化：二者之间的转化属于化学变化（碳原子排列方式改变，生成新物质）
  • C₆₀的结构与应用：足球状分子结构，无特殊标注性质，可用于装饰材料、新型材料研究
  • “碳”与“炭”的区别：“碳”指碳元素/纯净碳单质，“炭”指无定形碳（混合物）
  • 无定形碳的组成：木炭、活性炭、焦炭、炭黑统称无定形碳，由微小石墨晶体和少量杂质组成
  • 木炭的吸附性：因疏松多孔的结构具有吸附能力，可吸附色素异味
  • 活性炭的特性：经活化处理的无定形碳，吸附作用比普通木炭更强
  • 活性炭吸附实验：红墨水溶液中加活性炭，红色逐渐变浅最终无色（证明吸附性）
  • 质量守恒定律：参加化学反应的各物质的质量总和，等于反应后生成的各物质的质量总和
  • 质量守恒定律的微观解释：
    • 化学变化中，参加反应的反应物质量之和等于生成物质量之和
    • 化学变化中，原子的种类与个数不变
    • 化学变化中，元素的种类与质量不变
  • 硫酸铜溶液与氢氧化钠溶液反应：
    • 反应前总质量：85.9g，反应后总质量：85.9g
    • 反应方程式：CuSO_4 + 2NaOH \xlongequal{\quad} Cu(OH)_2\downarrow + Na_2SO_4
    • 实验现象：生成蓝色氢氧化铜沉淀
  • 稀盐酸与大理石反应：
    • 反应前总质量：78.4g，反应后总质量：78.4g（高老师失败了）
    • 反应方程式：CaCO_3 + 2HCl \xlongequal{\quad} CaCl_2 + H_2O + CO_2\uparrow
  • 稀盐酸与大理石反应需在密闭容器中进行，否则产生的二氧化碳气体会扩散到空气中，导致二氧化碳没有被测量，反应后总质量无法准确测量
  • 金属铜加热反应：
    • 实验现象：铜丝由红色变为黑色
    • 反应方程式：2Cu + O_2 \xlongequal{\triangle} 2CuO
    • 实验结论：反应前后质量不变（提到，没有做）
  • 书写化学方程式的原则：以客观事实为基础；遵守质量守恒定律
  • 书写化学方程式的步骤：写（写出反应物和生成物化学式）→ 配（配平方程式）→ 注（注明反应条件）→ 等（短线改等号）→ 标（标注生成物状态）
  • 化学方程式中的状态符号：↑表示气体（反应物无气体时标注），↓表示沉淀（反应物无固体时标注）
  • 化学方程式的含义：表示反应物、生成物和反应条件
  • 化学方程式的微观意义：表示各物质的粒子个数比
  • 化学方程式的质量意义：表示各物质的质量比（等于相对分子质量乘以化学计量数之比）
  • 根据化学方程式计算的步骤：设未知数→写方程式→算相对质量→列比例式→求解→作答
  • 示例1：C + O_2 \xlongequal{\text{点燃}} CO_2
    • 物质：碳与氧气在点燃条件下反应，生成二氧化碳
    • 微观：
      • 每1个碳原子和1个氧分子在点燃条件下反应，生成1个二氧化碳分子
      • 每12克碳与32克氧气反应，生成44克二氧化碳
  • 示例2：2H_2O \xlongequal{\text{通电}} 2H_2\uparrow + O_2\uparrow
    • 物质：水在通电条件下生成氢气和氧气
    • 微观：
      • 在通电条件下，每2个水分子反应生成2个氢分子和1个氧分子
      • 在通电条件下，每36克水分解，生成4克氢气和32克氧气
  • 化合反应：两种或多种物质生成一种物质，特点多变一，表达式：A+B+\dots\rightarrow C，特点是多变一
  • 化合反应举例：2H_2 + O_2 \xlongequal{\text{点燃}} 2H_2O
  • 分解反应：一种物质生成两种或多种物质，特点一变多，表达式：A\rightarrow B+C+\dots，特点是一变多
  • 分解反应举例：2H_2O \xlongequal{\text{通电}} 2H_2\uparrow + O_2\uparrow
  • 置换反应："单换单"，由一种单质与一种化合物反应，生成另一种单质和另一种化合物，表达式：A+BC→AC+B，特点是单换单
  • 置换反应举例：Fe + CuSO_4 \xlongequal{} FeSO_4 + Cu
  • 复分解反应："双交换"，由两种化合物互相交换成分，生成另外两种化合物，表达式：AB+CD\rightarrow AD+BC，特点是双交换
  • 复分解反应举例：NaOH + HCl \xlongequal{} NaCl + H_2O

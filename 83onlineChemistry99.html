番外篇 化学99条大全

本学期核心知识点（千万不要考试的时候往考卷上默99条哦！！！）

  • 不能在化学课上挑衅、激怒化学老师
  • 物理变化：无新物质生成的变化（如玻璃破碎）
  • 化学变化：有新物质生成的变化（如蜡烛燃烧）
  • 物理性质：无需化学变化就能体现的性质（如颜色、状态）
  • 化学性质：需通过化学变化才能体现的性质（如可燃性、酸碱性）
  • 元素符号书写规则：首字母大写，后续字母小写（如Fe）
  • 固体药品取用工具：
    • 块状：镊子
    • 粉末状：药匙或纸槽
  • 液体药品取用工具：
    • 少量：胶头滴管
    • 大量：倾倒法（标签向手心、瓶口紧挨容器口）
    • 定量：量筒（搭配胶头滴管）
  • 量筒读数方法：视线与液体凹液面最低处保持水平
  • 粗盐成分：主要成分为氯化钠（NaCl），含氯化镁、泥沙等杂质
  • 粗盐溶解本质：完全溶解粗盐中的可溶性物质
  • 粗盐提纯核心流程：溶解→过滤→蒸发
  • 量筒的选择：选择量程内最小的
  • 电子天平的使用：
    • 将电子天平放在水平桌面上，使水准泡在圈中央
    • 按“去皮”键进行去皮，不是归零、调零
    • 添加粗盐至示数接近5.0g（不能超过5.0g）时，用另一只手轻敲持药匙的手腕或用食指轻敲药匙柄
    • 用手指轻轻弹击称量纸，确保称量纸上没有粗盐附着
    • 称量纸上放无腐蚀性固体药品，烧杯里比本身小的任何东西都能放
  • 粗盐溶解操作要点及玻璃棒作用：加水，用玻璃棒搅拌，加速溶解
  • 溶解时所用的仪器：烧杯、玻璃棒
  • 实验仪器搭建顺序：从下往上、从左往右
  • 过滤操作要求（一贴、二低、三靠）：
    • 一贴：滤纸紧贴漏斗内壁，无气泡残留
    • 二低：
      • 滤纸边缘低于漏斗边缘
      • 漏斗内液面低于滤纸边缘
    • 三靠：
      • 烧杯尖嘴紧靠玻璃棒
      • 玻璃棒末端紧靠三层滤纸处
      • 漏斗下端管口紧靠烧杯内壁
  • 过滤时玻璃棒作用：引流
  • 过滤时所用的仪器为铁架台、漏斗、烧杯、玻璃棒；用品为滤纸
  • 蒸发时玻璃棒作用：搅拌，使液体受热均匀，防止液体飞溅
  • 蒸发时所用的仪器为铁架台、蒸发皿、酒精灯、玻璃棒、坩埚钳、电子点火器、陶土网（将受热后的蒸发皿放置在陶土网上冷却，以免损坏桌面或因骤冷导致蒸发皿破裂）
  • 蒸发停止时机：蒸发皿中有大量固体析出时，利用余热蒸干
  • 粗盐产率公式：产率=\frac{m_{\text{精盐}}}{m_{\text{粗盐}}} ×100%
  • 粗盐产率分析
    • 偏大原因：①蒸发后精盐未蒸干；②过滤时滤纸破损；③液面高于滤纸边缘
    • 偏小原因：①溶解时水太少导致精盐未完全溶解；②蒸发时液体溅出；③过滤时有液体残留；④称量时蒸发皿中有残留固体
  • 蒸馏水用量对粗盐提纯的影响：过多增加过滤、蒸发操作时间；过少不能将粗盐中可溶物完全溶解
  • 未说明药品用量时的取用规则：固体粉末铺满试管底部、块状取1块，液体取1~2mL
  • 酒精灯点燃方法：用火柴或电子打火器点燃，禁止用燃着的酒精灯引燃，串联酒精灯
  • 酒精灯熄灭方法：用灯帽盖灭，禁止用嘴吹灭
  • 试管加热时铁夹夹持位置：距试管口\frac{1}{3}处
  • 固体加热时试管口朝向：略向下倾斜，防止冷凝水倒流炸裂试管
  • 试管内液体加热量：不超过试管容积的\frac{1}{3}，避免液体沸腾飞溅
  • 加热仪器
    • 可直接加热：试管、蒸发皿、坩埚、燃烧匙
    • 需垫陶土网加热：烧杯、烧瓶、锥形瓶，使受热均匀
    • 不能加热：量筒、集气瓶、漏斗、胶头滴管
  • 试管加热前的要求：外壁必须干燥，先预热再集中加热
  • 胶头滴管使用要求：垂直悬空在容器口上方滴加，禁止伸入容器内
  • 实验室取用药品“三不”原则：不摸、不闻、不尝
  • 实验剩余药品处理方法：放入指定容器，不放回原瓶、不随意丢弃、不能给吕楷鑫喝、不能创造新的化学物质
  • 不要学习高老师忘记贴标签，导致浪费一节课来分清两瓶药品
  • 在实验室中切忌不遵守化学实验室守则
  • 空气的主要成分（体积分数）：氮气约78%、氧气约21%、稀有气体约0.94%、二氧化碳约0.03%、其他气体/杂质约0.03%
  • 氮气的性质与用途：无色无味气体、难溶于水，不与红磷反应/不燃烧/不助燃；用途为食品保鲜、作保护气
  • 稀有气体：化学性质很稳定，常用作保护气；通电时能发出不同颜色的光，可制作霓虹灯等电光源
  • 红磷燃烧测空气中氧含量（方程式）：2P + 5O_2 \xlongequal{\triangle} 2P_2O_5
  • 红磷燃烧测空气中氧含量（现象）：产生大量白烟，放热，冷却后水倒吸入集气瓶，体积约占集气瓶1/5
  • 红磷测氧含量结果偏差原因：
    • 偏小：红磷量不足、装置气密性差、未冷却至室温就打开止水夹
    • 偏大：未夹紧止水夹、点燃红磷后未及时塞紧瓶塞
  • 氧气的性质：物理性质（无色无味气体、密度略大于空气、难溶于水）；化学性质（助燃性，能与多种物质发生氧化反应）
  • 与氧气发生的反应是氧化反应
  • 氧化物的定义：由两种元素组成，且一种是氧元素的化合物
  • 碳的燃烧（现象）：空气中红热；氧气中发出白光、放热
  • 碳的燃烧（方程式）：C + O_2 \xlongequal{\text{点燃}} CO_2（充分燃烧）
  • 铁的燃烧（现象）：空气中不燃烧，仅发生缓慢氧化；氧气中火星四射、放热，生成黑色固体
  • 铁的燃烧（方程式）：3Fe + 2O_2 \xlongequal{\text{点燃}} Fe_3O_4
  • 铁在氧气中燃烧的实验注意事项：
    • 系火柴：引燃铁丝
    • 瓶底放水/细沙：防止高温熔融物溅落，导致集气瓶受热不均炸裂
  • 二氧化碳的物理性质：无色无味气体、密度比空气大、能溶于水
  • 二氧化碳与水的反应（方程式）：CO_2 + H_2O \xlongequal{\quad} H_2CO_3
  • 二氧化碳与水的反应（现象）：使紫色石蕊溶液变红
  • 碳酸受热分解（方程式）：H_2CO_3 \xlongequal{\triangle} CO_2\uparrow + H_2O
  • 碳酸受热分解（现象）：石蕊溶液由红色恢复为紫色
  • 二氧化碳与澄清石灰水的反应（方程式）：Ca(OH)_2 + CO_2 \xlongequal{\quad} CaCO_3\downarrow + H_2O
  • 二氧化碳与澄清石灰水的反应（现象）：澄清石灰水变浑浊（用于检验CO₂）
  • 工业制氧：采用分离液态空气法，利用各气体沸点不同（物理变化）
  • 启普发生器：适用于固体与液体反应制取气体，优点是随开随用、随关随停，不能加热
  • 实验室制氧气（加热高锰酸钾，方程式）：2KMnO_4 \xlongequal{\triangle} K_2MnO_4 + MnO_2 + O_2\uparrow
  • 实验室制氧气（过氧化氢催化，方程式）：2H_2O_2 \xlongequal{MnO_2} 2H_2O + O_2\uparrow
  • 实验室制氧气（加热氯酸钾，方程式）：2KClO_3 \xlongequal[\triangle]{MnO_2} 2KCl + 3O_2\uparrow
  • 实验室制二氧化碳（方程式）：CaCO_3 + 2HCl \xlongequal{\quad} CaCl_2 + CO_2\uparrow + H_2O
  • 实验室制二氧化碳不用硫酸的原因：生成微溶于水的CaSO₄，覆盖在碳酸钙表面，阻止反应继续进行
  • 多功能瓶有长短两根导管，长导管深入瓶底，短导管仅露出橡胶塞。可用于收集氧气、二氧化碳等
  • 多功能瓶长进短出收集氧气，带火星木条放短导管口复燃则满，因氧气密度大集满后从短管逸出
  • 多功能瓶长进短出收集二氧化碳，燃着木条放短导管口熄灭则满，因二氧化碳不助燃且密度大
  • 三种固液常温型气体发生装置对比：
    • 试管直连导管：装置最简易，固体液体一次性加入密封，操作快捷，但无法控制反应速率与启停
    • 分液漏斗+容器：通过旋钮控制液体滴加速率，精准调控反应速率，气密性好，无需液封
    • 长颈漏斗+容器：漏斗下端需液封防漏气，可随时添加液体，不能控制速率，搭配止水夹可实现反应启停
  • 发生装置选择：先看反应条件（加热或常温），再看反应物状态（固固、固液等）；块状固体适合搭配止水夹控制反应启停，粉末状固体易堵塞导管，加热时需在试管口放一团棉花
  • 气体收集的三种方法：排水法（适用于难溶于水、不与水反应的气体）、向上排空气法（适用于密度比空气大的气体）、向下排空气法（适用于密度比空气小的气体）
  • 物质的构成与组成（核心区分）：
    • 宏观（组成）：物质由元素组成，仅说种类、不说个数
    • 微观（构成）：物质由离子、分子、原子构成，既说种类、也说个数
  • 离子的定义与对应物质：带电荷的微观粒子；对应物质为金属化合物（如NaCl）
  • 分子的定义与对应物质：由原子构成的微观粒子；对应物质为非金属单质（如O₂、N₂）、非金属化合物（如CO₂、H₂O）
  • 原子的定义与对应物质：化学变化中的最小微观粒子；对应物质为金属单质（如Fe、Cu）、非金属固体单质（如C、P）、稀有气体（如He、Ne）
  • 元素的定义：质子数相同的同一类原子的总称（宏观层面，是原子的集合）
  • 微观粒子的基本性质：①体积小、质量小；②不断运动；③粒子间有间隔；④同种粒子性质相同，不同粒子性质不同
  • H₂O的宏微观含义：
    • 宏观：①代表物质（水）；②由氢元素和氧元素组成
    • 微观：①代表1个水分子；②1个水分子由2个氢原子和1个氧原子构成
  • 3CO₂的宏微观含义：
    • 化学式前加数字后，只能表示微观意义，无宏观意义
    • 微观：①代表3个二氧化碳分子；②1个二氧化碳分子由1个碳原子和2个氧原子构成
  • 原子的结构：原子由原子核（含质子、中子，氢原子无中子）和核外电子构成
  • 原子构成粒子的带电情况：质子（核内，正电）、中子（核内，不带电）、电子（核外，负电）
  • 核外电子排布规律：电子层最多容2n²个电子，最外层不超8个（第一层不超2个），先排内层再排外层
  • 元素的分布（含量较多的元素）：
    • 人体：氧（O）、碳（C）、氢（H）、氮（N）、钙（Ca）
    • 地壳：氧（O）、硅（Si）、铝（Al）、铁（Fe）、钙（Ca）
  • 元素周期表的基本排布：按原子序数排，周期数=电子层数，主族数=最外层电子数（0族除外）
  • 化合价的定义：表示形成化合物时，一个原子和其他原子相结合的数目
  • 化合价的规则：化合物中正负化合价代数和为0；单质中元素化合价为0
  • 常见元素的化合价：
    • +1价：K、Na、Ag、H
    • +2价：Ca、Mg、Ba、Zn、Cu、Fe（亚铁）
    • +3价：Al、Fe（铁）
    • -1价：F、Cl
    • -2价：O、S
  • 常见原子团的化合价：
    • +1价：NH₄⁺（铵根）
    • -1价：OH⁻（氢氧根）、NO₃⁻（硝酸根）
    • -2价：CO₃²⁻（碳酸根）、SO₄²⁻（硫酸根）
  • 金属化合物的读写规则：
    • 读法：从右向左读“某化某”
    • 写法：正价在前，负价在后
  • 非金属化合物的读写规则：
    • 读法：读“几某化几某”
    • 写法：正价在前，负价在后
  • 易混淆物质的分类：
    • 冰水混合物（H₂O）：属于化合物（纯净物）
    • 食盐（以NaCl为主要成分）：属于混合物
  • 原子结构模型（实心球模型）：道尔顿1803年提出，认为原子是不可再分的实心球体
  • 原子结构模型（葡萄干面包模型）：汤姆孙1903年提出，认为原子像蛋糕、电子像葡萄干嵌在其中（无核结构）
  • 原子结构模型（核式结构模型）：卢瑟福1911年提出，认为原子中心有带电原子核，核外电子绕核运动
  • 化学方程式书写的两条原则：①以客观事实为依据；②符合质量守恒定律（等号两边原子种类、数目相等，即配平）
  • 化学反应的原子变化规律：原子是化学变化中的最小微粒，反应前后原子的种类、个数不变
  • 化学方程式的符号标注规则：
    • 加热：用“△”表示
    • 气体生成物：反应物无气体时，用“↑”标注
    • 沉淀生成物：溶液中反应、反应物无难溶物时，用“↓”标注
    • 反应条件：写在等号上下

专题3 空气、氧气、二氧化碳

课题1 空气的成分

空气中含有哪些物质
  • 1. 红磷燃烧测定空气中氧气含量
    • （1）实验步骤（参考书P58）：
      1. 在100mL的量筒内加入80mL水，用弹簧夹夹紧乳胶管；
      2. 点燃燃烧匙内的红磷后，立即伸入容积为250mL的集气瓶中，并塞紧橡胶塞，观察并记录实验现象；
        • 红磷燃烧，产生大量白烟，放出热量
      3. 待红磷熄灭并冷却至室温后，打开弹簧夹，观察并记录实验现象；
        • 冷却后打开弹簧夹，烧杯中的水倒流进入集气瓶，进入水的体积约占集气瓶内空气总体积的1/5
    • （2）实验结论：空气中氧气的体积分数约为1/5，且空气是由多种物质组成的混合物。
    • （3）误差分析：
      •   测量结果偏小:
        •     红磷量不足，未能完全消耗瓶内氧气;
        •     装置气密性不佳，冷却过程中有空气进入;
        •     未冷却至室温就打开弹簧夹，瓶内气体受热膨胀导致进入的水偏少。
      •   测量结果偏大:
        •     点燃红磷后未及时塞紧橡胶塞，导致瓶内部分空气受热逸出;
        •     弹簧夹未夹紧，实验过程中有空气从胶皮管逸出。
    • 2. 空气的主要成分
      • （1）氮气：约占78%，是空气的主要成分，化学性质不活泼。
      • （2）氧气：约占21%，支持燃烧和呼吸，是维持生命活动的重要物质。
      • （3）稀有气体：约占0.94%，化学性质极不活泼，常用作保护气。
      • （4）二氧化碳：约占0.03%。
      • （5）其他气体和杂质：约占0.03%。
    洁净的空气为何如此重要

    空气污染

    • SO2(二氧化硫):酸雨
    • N2(氮气)、NO2(二氧化氮)、N2O4(四氧化二氮):氮氧化合物
    • PM2.5、PM10:可吸入颗粒物
    • CO2(二氧化碳):温室效应气体

    课题2 氧气二氧化碳的性质

    氧气有哪些性质
    • 1. 物理性质
      • 无色无味
      • 难溶于水
      • 密度比空气大
    • 2. 化学性质
      • 助燃性
    • 3. 氧化
      • 与氧气发生的反应是氧化反应
        （高中定义：凡是物质所含元素的化合价升高或失去电子的反应，就是氧化反应。）
      • 由两种物质组成且其中一种是氧元素的化合物是氧化物
    • 4.氧气有关反应
      物质 空气中 氧气中 化学方程式
      木炭 红热 发白光，放热
      C + O2 ═══（条件：点燃） CO2
      铁丝 不燃烧 火星四射，剧烈燃烧，生成黑色固体，放出大量热
      3Fe + 2O2 ═══（条件：点燃） Fe3O4
      磷 大量白烟，放热
      4P + 5O2 ═══（条件：点燃） 2P2O5
      镁 发出耀眼白光，放热，生成白色固体
      2Mg + O2 ═══（条件：点燃） 2MgO
      铁丝燃烧实验补充说明：
      1. 反应物浓度越大，铁丝燃烧现象越剧烈；
      2. 实验中需用火柴引燃铁丝，若无引燃物铁丝无法自行燃烧；
      3. 集气瓶底部需预先加水或铺一层细沙，防止反应生成的高温熔融物溅落导致集气瓶炸裂。
    二氧化碳有哪些性质
    • 1. 物理性质
      • 无色无味气体
      • 能溶于水
      • 密度比空气大
      • 固态二氧化碳（干冰）易升华
    • 2. 化学性质
      • 不可燃、不助燃
      • 能与水发生反应生成碳酸
      • 能与澄清石灰水（氢氧化钙）发生反应
    • 3. 二氧化碳有关反应
      • 反应物 实验现象 化学方程式 补充说明
      二氧化碳 + 水 无明显现象（滴加石蕊溶液后石蕊变红）
      CO2 + H2O ═══ H2CO3
      		 生成的碳酸不稳定，加热易分解
      碳酸 加热后，滴加石蕊的溶液由红变紫
      H2CO3 ═══ （ 条件：Δ） CO2↑ + H2O
      		 碳酸分解释放二氧化碳
      二氧化碳 + 澄清石灰水 澄清石灰水变浑浊
      Ca(OH)2 + CO2 ═══ CaCO3↓ + H2O
      		 该反应常用于检验二氧化碳气体

    课题3 氧气和二氧化碳的制备

    怎样获得氧气
    • 一、工业制取氧气
      • 原理：利用空气各成分沸点不同（物理变化）
        • 氮气沸点：-196℃；氧气沸点：-183℃
      • 步骤：净化空气 → 压缩冷却液化 → 升温分离（氮气先汽化） → 收集液氧
    • 二、实验室制取氧气
      • 1. 加热高锰酸钾（KMnO4）
        • 化学式：

          2KMnO₄ ═══ （条件：Δ） K₂MnO₄ + MnO₂ + O₂↑

        • 特点：需要加热，反应稳定
        • 实验操作步骤（豆沙包生成）
          • 查：检查装置气密性（如上）；
          • 装：将高锰酸钾粉末平铺在试管底部，试管口放一团棉花（防止粉末进入导管）；
          • 定：固定试管（试管口略向下倾斜，防止冷凝水倒流炸裂试管）；
          • 点：点燃酒精灯，先预热试管，再集中加热药品部位；
          • 收：待导管口有连续均匀气泡冒出时，开始收集氧气；
          • 离：收集完毕后，先将导管移出水面；
          • 熄：最后熄灭酒精灯（防止水倒流裂试管）。
        • 注意事项
          1. 试管口必须略向下倾斜：防止加热时试管口的冷凝水倒流，炸裂试管；
          2. 试管口放棉花：防止高锰酸钾粉末随气流进入导管，堵塞导管；
          3. “先离后熄”：停止加热前先移出导管，再熄灭酒精灯，避免水倒吸；
          4. 加热要预热：防止试管局部温度过高，受热不均而炸裂；
      • 2. 过氧化氢（H2O2）分解（二氧化锰催化）
        • 化学式：

          2H₂O₂ ═══ （条件：MnO₂做催化剂） 2H₂O + O₂↑

        • 特点：无需加热，操作简便
      • 3. 电解水（H2O）
        • 化学式：

          2H₂O ═══ （条件：通电） 2H₂↑ + O₂↑

        • 特点：能耗高，实验室少用（主要用于演示水的组成）
      • 4. 加热氯酸钾（KClO3）（二氧化锰催化）
        • 化学式：

          2KClO₃ ═══（条件：MnO₂做催化剂、Δ）2KCl + 3O₂↑

        • 特点：需要加热，氧气产量高
    • 三、重点
      • 1）装置气密性检查方法
        1. 将导管一端浸入水中，用手紧握试管外壁（或用酒精灯微热试管）；
        2. 若导管口有连续气泡冒出，松开手后导管内形成一段稳定的水柱，说明气密性良好；
        3. 若无气泡/水柱，需检查装置连接处（如橡胶塞、导管接口）是否松动，重新组装后再次检查。
      • 2）催化剂
        • 定义：催化剂是能改变化学反应速率，而本身的质量和化学性质在反应前后都没有发生改变的物质
        • 核心特征：
          1. 改变化学反应速率（可加快，也可减慢，实验室制氧中多为加快）；
          2. 反应前后质量、化学性质不变（物理性质可能改变）；
          3. 不改变反应的最终生成物种类和产量；
          4. 具有选择性（一种催化剂通常只对某一反应或某类反应起作用）。
      • 3）三种集气方法
        • 排水集气法
          1. 原理：氧气不易溶于水，且不与水反应；
          2. 优点：收集的氧气纯度高；
          3. 缺点：收集的氧气含有水蒸气，需干燥。
        • 向上排空气法
          1. 原理：氧气密度（1.429g/L）略大于空气（1.293g/L）；
          2. 优点：收集的氧气干燥；
          3. 缺点：纯度较低，需验满。
        • 向下排空气法
          1. 适用条件：密度比空气小，且不与空气成分反应的气体；
          2. 优点：操作简便、气体干燥；
          3. 缺点：纯度较低，需验满。
    实验室中如何制取二氧化碳
    • 实验室制取CO₂的原料选择对比
      • 1. 稀盐酸 + 块状石灰石
        • 反应：CaCO₃ + 2HCl ═══ CaCl₂ + CO₂↑ + H₂O
        • 优点：反应速率适中，便于控制，持续产生CO₂
        • 产物：CaCl₂易溶于水，不会覆盖石灰石表面，反应可顺利进行
      • 2. 稀盐酸 + 粉末状石灰石
        • 反应：CaCO₃ + 2HCl ═══ CaCl₂ + CO₂↑ + H₂O
        • 缺点：粉末状石灰石与稀盐酸接触面积大，反应速率过快，不易控制，不利于收集CO₂
      • 3. 稀硫酸 + 块状石灰石
        • 反应：CaCO₃ + H₂SO₄ ═══ CaSO₄ + CO₂↑ + H₂O
        • 缺点：生成的CaSO₄是微溶于水的物质，会覆盖在石灰石表面，阻止反应进行
    • 实验室制取CO₂的原理
      • 化学方程式：CaCO₃ + 2HCl ═══ CaCl₂ + CO₂↑ + H₂O
    • 发生装置选择依据
      • 反应物状态：固体（块状大理石） + 液体（稀盐酸）
      • 反应条件：常温（不需要加热）
      • 装置类型：固液常温型发生装置
    • 收集装置选择依据
      • 收集方法：向上排空气法
      • 选择理由：CO₂密度比空气大（CO₂密度1.977g/L＞空气1.293g/L），且能溶于水并与水反应，不能用排水集气法
    • CO₂的验满方法
      • 操作：将燃着的木条放在集气瓶口
      • 现象与结论：若木条熄灭，说明CO₂已收集满（利用CO₂不燃烧、不支持燃烧的性质）
    • 实验操作步骤（豆沙包生成）
      • 检查装置气密性：将导管一端浸入水中，用手紧握锥形瓶外壁，导管口有气泡冒出则气密性良好
      • 装入药品：先加块状大理石，再加入稀盐酸（长颈漏斗末端需液封）
      • 收集气体：将导管伸入集气瓶底部，用向上排空气法收集
      • 验满：将燃着的木条放在集气瓶口，木条熄灭则验满
      • 整理装置：实验结束后，先移除导管，再清理药品
    • 重点
      • 1）启普发生器
        • 适用条件
          • 反应物为块状固体与液体
          • 反应不需要加热
          • 生成的气体难溶于反应液体
          • 操作原理
            • 打开活塞：装置内压强减小，液体与块状固体接触，反应开始
            • 关闭活塞：装置内压强增大，液体被压回球形漏斗，与固体分离
          • 优点：随开随用、随关随停，可反复使用，操作简便
      • 2）多功能瓶
        • 收集气体
          ①空气
          ②排水
        • ρ大走长管，ρ小走短管

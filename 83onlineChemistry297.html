番外篇 化学99条大全

本学期核心知识点（千万不要考试的时候往考卷上默99条哦！！！）

  • 不能在化学课上挑衅、激怒化学老师
  • 上课禁止写作业（刘育君除外）
  • 考试结束后需立刻停笔，不能拿着卷子冲出教室
  • 分散系包含溶液、浊液等，都属于混合物
  • 溶液是均一、稳定、外观澄清透明的混合物，例如食盐水
  • 溶液是混合物，不是纯净物
  • 溶液不一定无色，如硫酸铜溶液是蓝色的
  • 浊液又分为乳浊液与悬浊液
    • 乳浊液是两种互不互溶的液体混合形成的分散系，例如油水混合物
    • 悬浊液是固体和不互溶的液体混合形成的分散系，例如泥水
  • 被溶解的物质叫做溶质，溶解其他物质的物质叫做溶剂
  • 两种液体互相溶解时，通常以量少者为溶质，量多者为溶剂；当溶液中有水存在时，不论水量多少，水都是溶剂
  • 酒精、汽油等也是常用的溶剂
  • 医用碘酒中溶质是碘单质，溶剂是酒精
  • KNO₃溶于水吸热、溶液温度降低；NaOH溶于水放热、溶液温度升高
  • 一定温度下，一定量溶剂中不能继续溶解某溶质的溶液为该溶质的饱和溶液
  • 饱和溶液与不饱和溶液可相互转化
    • 饱和溶液增加溶剂、改变温度变为不饱和溶液
    • 不饱和溶液增加溶质、恒温蒸发溶剂、改变温度变为饱和溶液
  • 固体物质溶解性的影响因素有溶质种类、溶剂种类、温度
  • 气体物质的溶解性除溶质、溶剂、温度外，还受压强影响
  • 溶解性与溶剂多少、是否搅拌、溶质颗粒大小无关；搅拌、把固体粉碎只能加快溶解速率，不能使溶质溶得更多
  • 氯化钠、蔗糖很容易溶解在水中，能在水中溶解的物质具有亲水性；食用油不易溶于水、能溶于汽油等有机溶剂，能在有机溶剂中溶解的物质具有亲油性
  • 肥皂、洗洁精、洗发液中主要发挥去污作用的表面活性剂既有亲油性又有亲水性
  • 洗涤剂去油污是利用乳化作用：使油污分散在水中，随水冲走
  • 溶解度（S）指一定温度下，100g溶剂中达到饱和时/最多所能溶解的溶质质量，单位为g
  • 20℃时氯化钠溶解度36g，有三层含义
    • 20℃时，100g水中最多溶解36g氯化钠
    • 20℃时，100g水中溶解36g氯化钠，溶液恰好达到饱和状态
    • 20℃时，每136g氯化钠饱和溶液中含有36g氯化钠、100g水
  • 饱和溶液里，m质 + m剂 = m液
  • 饱和溶液中溶解度的计算公式
    • \dfrac{S}{100}=\dfrac{m_{\text{质}}}{m_{\text{剂}}}
    • \dfrac{S}{S+100}=\dfrac{m_{\text{质}}}{m_{\text{液}}}
  • 大多数固体物质的溶解度随温度升高而增大，如硝酸钾、硝酸钠
  • 少数固体物质的溶解度受温度变化影响很小，如氯化钠
  • 极少数固体物质的溶解度随温度升高而减小，如氢氧化钙（反常）
  • 气体的溶解度随压强增大而变大
  • 溶解度曲线上的点代表对应温度下的饱和溶液，曲线下方的点代表不饱和溶液
  • 晶体是拥有规则几何外形的固体，部分晶体带有结晶水
  • 五水合硫酸铜CuSO₄·5H₂O俗称蓝矾、胆矾，属于结晶水合物
  • 蒸发结晶：适用于几乎所有物质，优点是得到全部溶质，缺点是耗时长，如 NaCl
  • 降温结晶（蒸发溶剂浓缩→降温）：适用于t↑S↑（溶解度随温度升高而增大）的物质，优点是方便，缺点是无法全部析出，如 KNO₃
  • 溶液的浓度可以用溶质的质量分数（C%，也可用 ω 表示）表示（表示浓度的方法不止一种）
  • C% = \dfrac{m_{\text{质}}}{m_{\text{液}}}\times 100\%（部分占整体的比例）
  • 含义：0.9% 的 NaCl 溶液表示每100g 溶液中含有 0.9g NaCl
  • 溶液各部分的组成和性质完全相同，每一部分的溶质质量分数、密度、颜色都一样
  • 一瓶溶液倒出一部分，倒出部分与剩余部分的溶质质量分数、密度、溶解度都不变，只是溶质、溶剂、溶液的总质量变少
  • 温度不变时某物质的溶解度不变；饱和溶液恒温蒸发析出晶体后仍为饱和溶液，溶质质量分数不变
  • 配制一定溶质质量分数的溶液步骤：计算、称量、溶解、装瓶贴标签
  • 配制 100g 10% 的 NaCl 溶液：需 NaCl 10g、水 90mL
  • 装瓶后贴标签，注明溶质质量分数和溶液名称
  • 用浓溶液配制稀溶液的步骤：计算、量取、混匀、装瓶贴标签
  • 溶液稀释前后溶质质量不变：m_{\text{质浓}}=m_{\text{质稀}}
  • C\%_{\text{浓}}\times m_{\text{液浓}}=C\%_{\text{稀}}\times m_{\text{液稀}}
  • 例：把 20% 的溶液配成 5% 的溶液 100g，20\%\times m_{\text{液浓}}=5\%\times 100\text{g}，解得 m_{\text{液浓}}=25\text{g}
  • 稀释时加水质量 = 稀溶液质量 − 浓溶液质量
  • 配制与稀释的注意事项
    • 称量：固体用托盘天平称取，液体用量筒量取
    • 溶解和稀释都在烧杯中进行，量筒只能量取液体，不能在量筒中溶解或稀释
    • 量筒读数时视线要与液体凹液面的最低处保持水平；仰视读数偏小，俯视读数偏大
    • 装瓶时不小心洒出部分溶液，不影响C%
  • 误差分析
    • 偏小原因：溶质不纯、称量时溶质撒落、量取水时仰视读数、溶解前烧杯内壁有水
    • 偏大原因：量取水时俯视读数
  • 酸碱指示剂是能跟酸或碱的溶液起作用而显示不同颜色，从而通过颜色变化判断溶液酸碱性的物质
  • 紫色石蕊试液遇酸性溶液变红，遇碱性溶液变蓝，遇中性溶液不变色
  • 无色酚酞试液遇碱性溶液变红，遇酸性和中性溶液不变色
  • 记忆口诀：石蕊——酸红碱蓝中性紫；酚酞——酸中不变碱变红
  • 酸由 H^+ 和酸根离子组成
  • 碱由金属离子（或 NH4+）和 OH^- 组成
  • 酸按强弱分：强酸（H2SO4、HCl、HNO3）、弱酸（H2CO3）
  • 酸按可电离出的 H^+ 个数（元数）分：一元酸（HCl、HNO3）、二元酸（H2SO4、H2CO3）、多元酸（H3PO4）
  • 酸按是否含氧分：含氧酸（H2SO4、HNO3、H2CO3）、无氧酸（HCl、HF、H2S）
  • 浓盐酸有挥发性，打开瓶盖瓶口出现白雾（HCl 气体溶于空气中的水蒸气形成盐酸小液滴）
  • 浓硫酸有吸水性（可作干燥剂）、脱水性（能将有机物中的 H、O 按 2:1 的比例脱去，使有机物碳化）
  • 浓盐酸挥发使溶质、溶液质量减小，溶质质量分数减小；浓硫酸吸水使溶剂、溶液质量增大，溶质质量分数减小
  • 碱按溶解性分：可溶性碱（NaOH、KOH、Ba(OH)2、Ca(OH)2、NH3·H2O）；难溶性碱（除可溶性碱外）
  • 碱按强弱分：强碱（NaOH、KOH、Ca(OH)2、Ba(OH)2）；弱碱（除强碱外）
  • 氢氧化钠 NaOH：俗称火碱、烧碱、苛性钠，易潮解
  • 氢氧化钠与二氧化碳反应
    2NaOH + CO_2 = Na_2CO_3 + H_2O
  • 氢氧化钙 Ca(OH)2：俗称熟石灰、消石灰，微溶于水
  • 氢氧化钙与二氧化碳反应
    Ca(OH)_2 + CO_2 = CaCO_3\downarrow + H_2O
  • 澄清石灰水（氢氧化钙水溶液）可用于检验 CO2（变浑浊）
  • 一水合氨 NH3·H2O：易挥发
  • 有颜色的碱
    • 氢氧化铜 Cu(OH)2：蓝色沉淀
    • 氢氧化铁 Fe(OH)3：红褐色沉淀
  • 镁与稀硫酸反应，镁带表面产生气泡（盐酸也能反应）
    Mg + H_2SO_4 = MgSO_4 + H_2\uparrow
  • 氧化铜与稀硫酸反应：黑色固体溶解，生成蓝色溶液（盐酸也能反应）
    CuO + H_2SO_4 = CuSO_4 + H_2O
  • 氧化铁与稀硫酸反应，生成黄色溶液（盐酸也能反应）
    Fe_2O_3 + 3H_2SO_4 = Fe_2(SO_4)_3 + 3H_2O
  • 碳酸钙与稀硫酸反应，产生气泡（盐酸也能反应）
    CaCO_3 + H_2SO_4 = CaSO_4 + H_2O + CO_2\uparrow
  • 氯化钡与稀硫酸反应，产生白色沉淀（盐酸不能反应）
    BaCl_2 + H_2SO_4 = BaSO_4\downarrow + 2HCl
